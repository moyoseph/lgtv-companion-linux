# Security policy

## Supported versions

Only the latest released version receives fixes. Please upgrade before
reporting (`pip install --upgrade lgtvcompanion`).

## Reporting a vulnerability

Please report security issues **privately** rather than opening a public issue:

- Use GitHub's [private vulnerability reporting](https://github.com/moyoseph/lgtv-companion-linux/security/advisories/new)
  (Security → Report a vulnerability), or
- email the maintainer.

I'll acknowledge as soon as I can and keep you posted on a fix. Thanks for
disclosing responsibly.

## Build provenance (SLSA Level 3)

Releases are built entirely by GitHub Actions and carry **SLSA Build Level 3**
provenance, generated by the audited
[`slsa-github-generator`](https://github.com/slsa-framework/slsa-github-generator)
reusable workflow (signing happens in an isolated context that the build can't
influence — the requirement for Level 3). The signed `multiple.intoto.jsonl`
attached to each release covers **all** artifacts: the wheel, sdist, `.deb`,
`.rpm`, and Arch package. Verify any of them with
[`slsa-verifier`](https://github.com/slsa-framework/slsa-verifier) — see
[*Verifying a release*](README.md#verifying-a-release-slsa-level-3) in the
README. PyPI artifacts additionally carry PEP 740 attestations that `pip`
verifies automatically.

## Scope notes

This tool controls TVs on your local network over the LG SSAP protocol
(`wss://<tv>:3001`). Pairing keys are stored locally (`/var/lib/lgtv-companion/keys/`
in system mode, `~/.local/state/lgtv-companion/` in user mode). It performs no
outbound calls except the optional, opt-in daily GitHub release check.
